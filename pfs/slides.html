Xyh Tamura

Creative technologist · artist-researcher · singer-songwriter

Xyh Tamura is a Filipino/Ilonggo-Japanese creative technologist and artist-researcher based in Manila. The practice investigates creative code as a poetic and generative medium across browser instruments, spatial notation, electronic literature, and visual algorithms. Rather than working inside closed creative software, Xyh builds open, executable web-native systems that let computation, language, and sound shape one another.

Art game · procedural environment

Cornice 2026

Procedural ASCII ecosystem and spatial poem set on a nocturnal city balcony · browser canvas and Web Audio synthesis

A browser art game and procedural ASCII ecosystem set on a nocturnal apartment balcony. Players navigate a grid world with keyboard controls to inspect botanical specimens, encounter shifting weather states, and trigger ambient Web Audio synthesis.

The system models ecological interaction through deterministic cellular automata rules, ambient sound synthesis, and dynamic text generation: visitors navigate a living terminal matrix where flora, insects, and atmospheric conditions evolve across continuous diurnal cycles as an inhabitable poem.

Coordinate systems · notation & spatial text

Stanzuary · Tabota Roll · Cycla 2025→

Spatial score and 3D text editor · open score format in hertz · recursive metrical grammar

Stanzuary is a 3D WebGL score and text editor that arranges musical events, phonemes, and text fragments across a navigable three-dimensional coordinate space.

Tabota is a plain-text score format and JavaScript runtime that stores pitch continuously in hertz rather than quantized MIDI note numbers, supporting Bézier glides and microtonal inflections.

Cycla is a formal grammar and parser for nested, additive, and non-isochronous time structures, compiling compact .cyc tree expressions into executable timelines.

Browser-native compositional systems

plica · Cutline · Glossolalia · LOVE-LETTER-FOR-YOU.TXT 2025–2026

Four browser-native generative and poetic systems

Generative collage

plica

An interactive electronic literature piece structured as an infinitely unfolding sheet of crumpled paper. Clicking any closed facet unfolds it into view and recalculates adjacent fold creases into new branching poetic texts, images, and color fields without ever resetting opened panels.

API poetry deck

Cutline

A live generative poetry web application that fetches text from public web APIs, parses the incoming language into poetic stanzas, and displays them as a continuous oracle deck.

Formant synthesis

Glossolalia

A browser vocal synthesis instrument where International Phonetic Alphabet (IPA) characters move as physics-enabled rigid bodies. Their coordinate positions on screen directly modulate the first two formant frequencies of a vocal-tract filter.

Executable poetry

LOVE-LETTER-FOR-YOU.TXT

An interactive web poem built around the decompiled code of the 2000 ILOVEYOU computer worm. As the user reads, the script executes in the browser, replacing text lines with file replication commands until the page collapses.

Generative deformation · non-grid glitch

Sgueltch — Pixel Lesions · TypeBojangler · goopCodecs 2025–2026

One aesthetic proposition distributed across three executable systems

Pixel Lesions is a browser image processing tool that sorts pixel matrices along biological spreading trajectories rather than horizontal scanlines.

TypeBojangler is a typographic tool that dynamically distorts OpenType font vector outlines in CSS text nodes using seeded per-character noise.

goopCodecs is a media glitching tool that injects controlled byte mutations into multimedia binary containers, generating organic video and audio compression artifacts.

Non-causal media processing

Hindcasts 2025–2026→

Hindcasts is a suite of offline audio and video tools that process a static file as a complete span, operating in both temporal directions before events arrive.

Remanence

An offline audio and video processor that simulates magnetic tape print-through and tape-spool magnetic hysteresis.

Metachamber

An offline acoustic reverberator that measures forthcoming gaps between notes to tailor reverb decay lengths exactly to future silences.

Pythia

An acausal granular delay and sidechain processor with negative delay, lookahead ducking, and pitch spray.

Prolepsis

An offline video feedback generator that renders anticipatory optical particle trails and precursor echoes prior to visual motions.

Sounder

A multi-band dynamic audio processor that computes time-occupancy amplitude histograms across an entire audio file, letting users redraw custom compression curves without threshold attack/release pumping.

CyberScotoma

An offline video glitch processor that freezes localized screen cells and populates them with image data sampled from future video frames.

Algorithmic visual systems

Bakezuri · DHuenut · Benzaiten · Aeropane 2025–2026

Four image systems with inspectable and editable physical and mathematical models

Fluid diffusion

Bakezuri

A browser canvas simulation that models ink diffusion, capillary flow, and pigment fixation across fibrous paper textures.

Color topology

DHuenut

An interactive color picker and palette generator that maps the color wheel across a continuous 3D torus topology to expose harmonic color pathways.

Acoustic warping

Benzaiten

An image processing tool that displaces and distorts 2D bitmap textures using real-time 2D acoustic wave and fluid force simulations.

Optical transport

Aeropane

An optical shader tool that calculates dielectric light scattering, internal refraction, and surface textures to transform 2D images.
