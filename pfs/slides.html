Xyh Tamura

Creative technologist · artist-researcher · singer-songwriter

Xyh Tamura is a Filipino/Ilonggo-Japanese creative technologist and artist-researcher based in Manila. The practice investigates creative code as a poetic and generative medium across browser instruments, spatial notation, electronic literature, and visual algorithms. Rather than working inside closed creative software, Xyh builds open, executable web-native systems that let computation, language, and sound shape one another.

Art game · procedural environment

Cornice 2026

Procedural ASCII ecosystem and spatial poem set on a nocturnal city balcony · browser canvas and Web Audio synthesis

A procedural ASCII ecosystem and spatial poem set on a nocturnal city balcony. Grid navigation, weather states, inspectable text specimens, and browser synthesis make the balcony an inhabitable writing surface.

The work models ecological interaction through deterministic cellular rules, ambient Web Audio synthesis, and dynamic text generation: visitors navigate a living terminal matrix where flora, insects, and atmospheric conditions evolve across continuous diurnal cycles. It operates as an expansive interactive sketch—an inhabitable poem running entirely within standard web technologies.

Coordinate systems · notation & spatial text

Stanzuary · Tabota Roll · Cycla 2025→

Spatial score and 3D text editor · open score format in hertz · recursive metrical grammar

Stanzuary arranges text, phonemes, and musical events in three-dimensional WebGL coordinate space, turning reading into spatial navigation.

Tabota stores pitch continuously in hertz rather than quantized MIDI note numbers, supporting Bézier glides and microtonal inflections.

Cycla parses nested, additive, and non-isochronous time structures from compact .cyc tree expressions into executable timelines.

Browser-native compositional systems

plica · Cutline · Glossolalia · LOVE-LETTER-FOR-YOU.TXT 2025–2026

Four browser-native generative and poetic systems

Generative collage

plica

A crumpled paper picked up from the road that unfolds indefinitely. Touching a closed panel opens it and the ragged edge re-creases into a different set of possible next panels; what is already open never moves again.

API poetry deck

Cutline

A live generative poetry deck that retrieves language from public APIs, cuts it into poems, and returns each result to the deck. An oracle assembled from outside language and network traces.

Formant synthesis

Glossolalia

International Phonetic Alphabet glyphs drift as rigid bodies in a 2D field. Their positions control the first two formants of a vocal-tract filter, synthesizing vocal gestures that never resolve into words.

Executable poetry

LOVE-LETTER-FOR-YOU.TXT

A web poem built on the 2000 ILOVEYOU visual basic script. The text systematically replaces its own lines with replication commands until it performs its own complete viral collapse.

Generative deformation · non-grid glitch

Sgueltch — Pixel Lesions · TypeBojangler · goopCodecs 2025–2026

One aesthetic proposition distributed across three executable systems

Pixel Lesions replaces scanline glitch with biological spreading models. Organic lesion masks govern non-uniform sorting along fluid trajectories.

TypeBojangler deforms OpenType glyph contours with seeded per-character noise, warping typography dynamically inside CSS text nodes.

goopCodecs corrupts binary multimedia payloads with structural byte mutations, generating continuous, organic compression artifacts.

Non-causal media processing

Hindcasts 2025–2026→

Hindcasts is a suite of offline audio and video tools that process a static file as a complete span, operating in both temporal directions before events arrive.

Remanence

Models magnetic print-through and acausal hysteresis across wound tape reels, for audio and video.

Metachamber

An offline reverb that maps release-to-onset silences, fitting decay tails to future onset gaps with masking credit.

Pythia

An acausal granular delay and sidechain processor with negative delay, lookahead ducking, and pitch spray.

Prolepsis

Video feedback computed across a whole clip, with the time arrow free: a causal wake, an anticipatory precursor swarm ramping into each transient, or both at once, zero-phase.

Sounder

Dynamics without detection. It reads the file, builds the time-occupancy histogram over level, and hands back the transfer curve to redraw. One window control walks from memoryless waveshaping to whole-piece normalization, per frequency band.

CyberScotoma

A scotoma is a hole in the visual field; a migraine aura is a hole that arrives before the pain it announces. Held cellular regions stop refreshing and fill with donor content drawn from later in the clip, so the future bleeds backward.
