Hysteresis

Showing

memoryless — nonlinear — opening — band —

Memory is the share of the current that requires internal state. Harmonic is the share above the fundamental; a linear capacitance produces none. Opening is the current still flowing as the voltage crosses zero, so 0% is a pinched loop. A memristor reads harmonics with a pinched loop; a capacitance in parallel reads the reverse. Mould adds that capacitance.

One band's element, over the last 32 ms. An input has no cycle to fold onto, so this is a sliding window rather than one loop — a scope in X–Y mode with a voice on it draws exactly this. Memoryless is the share of the current no single-valued i(v) can account for, so a plain resistor reads 0 and a capacitance reads high. Nonlinear is what is left after the best linear model of the band, so a resistor and an RC network both read 0 and only a genuinely nonlinear element reads high — that is the pair that tells a memristor from the mould. Band is set in the Voice panel.

Voice

The input runs through the circuit built above — the same M(q), mould, reinforcement and senescence, one element per band. Input sets how far each band drives its element and is the timbre control; Mix crossfades against the untouched signal. Tilt scales μ with band centre: at 1 every band reaches its element, at 0 only the low ones do, because charge integrates current and so hears the input with a 1/f weight. Bars are each band's charge span; the line under them is the wear that band has deposited, which is why the substrate ends up a record of what was said into it.

Circuit

branches 1 mould share — total —

One drive across every branch. Colony adds memristive branches and sets their thickness; Mould adds the capacitor beside them, which carries current a quarter cycle out of step and holds no state. The cycle is replayed at 0.5 Hz — the element runs at the note's pitch.

One branch per band, each carrying its own filtered share of the input, and when Mould is up each carries its own capacitance beside its element — that is where the capacitance is, and it is why sibilants come through least processed, since a band's capacitive current goes as its own frequency. Percentages are live current shares, not a replayed cycle: an input has no cycle. The marked branch is the one the Hysteresis loop is showing.
